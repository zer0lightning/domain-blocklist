# ============================================================
# Ethereum Public RPC Gateway Domains — Threat Intel Blocklist
# Version: 2.0 | Updated: 2026-05-25
# ============================================================
# PURPOSE:
#   Block domains abusable as Ethereum JSON-RPC C2 channels.
#   Infostealers use eth_call to smart contracts via these
#   public gateways to retrieve encoded C2 configs.
#
# SOURCES (all verified):
#   [1] ChainList JSON API  — chainlist.org/rpcs.json (chain ID 1)
#   [2] ethereum-lists/chains — github.com/ethereum-lists/chains eip155-1.json
#   [3] DefiLlama extraRpcs — github.com/DefiLlama/chainlist extraRpcs.js
#   [4] CompareNodes library — comparenodes.com/library/public-endpoints/ethereum
#   [5] Block Builders list — github.com/blue-searcher/awesome-block-builders
#
# THREAT CONTEXT:
#   Smart contract IoC: 0x8C4a70eF16836f35Ca8CdcEF2eBAC301E0A1fa75
#   Method abused: eth_call (JSON-RPC POST)
#   Detection: POST to these domains with body containing "eth_call"
#
# REMOVED/EXCLUDED (with reason):
#   mainnet.infura.io      — requires API key, no public anonymous access
#   mainnet.eth.cloud.ava.do — personal/home node, not stable public RPC
#   ethereumnodelight.app.runonflux.io — community flux node, ephemeral
#   main-light.eth.linkpool.io — deprecated, LinkPool shut down
#
# FORMAT: One domain per line (DNS/firewall/SIEM compatible)
# ============================================================
